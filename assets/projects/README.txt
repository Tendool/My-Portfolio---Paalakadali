NOTE ON CLIENT WORK
The first, third and fourth entries are Yitro Global work and are labelled by
capability only — no internal project names appear anywhere on the site. Keep
it that way if you swap the captions, and avoid screenshots showing client
branding, real employee data or internal URLs.

ADDING MORE SHOTS
Open index.html, find the GALLERY array, copy any row, give it a new filename:
  { f:'firebot-02.jpg', cat:'robotics', tag:'Fire Fighting Robot', cap:'Pump assembly close-up' },

Aim for roughly 1600px on the long edge, landscape framing (the viewer is
16:10), and keep files under ~400KB so the page stays fast.
